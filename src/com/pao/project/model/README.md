Proiectul este o aplicatie Java orientata pe obiecte care simuleaza o platforma de tip food delivery. Sistemul gestioneaza mai multe firme de restaurante, iar fiecare firma poate avea mai multe restaurante, fiecare cu propriul meniu de produse.
Aplicatia permite administrarea clientilor, soferilor si comenzilor. 
Utilizatorii pot plasa comenzi, acestea sunt asignate unui sofer disponibil, iar apoi pot fi finalizate. Exista functionalitati, cum ar fi afisarea restaurantelor cu cele mai multe comenzi.


Operatii:

"0. Exit
"1. Adauga firma
"2. Adauga client
"3. Adauga restaurant
"4. Adauga sofer
"5. Plaseaza comanda
"6. Asigneaza sofer comenzii
"7. Finalizeaza livrare
"8. Listeaza comenzi client
"9. Top restaurante
"10. Adaugare meniu restaurant
