# Proiect PAO - Catalog Scolar

## 1.1 Lista de Actiuni / Interogari
1. Adaugarea unui nou student in sistem.
2. Adaugarea unui profesor si asocierea cu o materie.
3. Crearea unei materii noi.
4. Inregistrarea unei note pentru un student la o anumita materie.
5. Cautarea unui student dupa ID-ul unic.
6. Listarea tuturor studentilor dintr-o anumita clasa/grupa.
7. Afisarea tuturor notelor unui student.
8. Calcularea mediei generale a unui student.
9. Sortarea studentilor alfabetic dintr-o lista.
10. Stergerea unui student din evidenta.

## 1.2 Tipuri de obiecte (Clase)
1. `Persoana` (clasa abstracta)
2. `Student` (extinde Persoana)
3. `Profesor` (extinde Persoana)
4. `Materie`
5. `Nota`
6. `ClasaScolara` (grup de studenti)
7. `IdentificatorScolar` (clasa imutabila)
8. `Catalog` (clasa principala de management)
